Sister clan · RS3

Clan Hall

Discord bot for live Jagex roster, XP snapshots, citadel cap self-report, and a promotion shortlist. No AI needed after you open this page.

Not an official Jagex product. Officers still change ranks in Clan Settings by hand.

Download ZIP Source on GitHub

Load it

  1. Click Download ZIP above. Unzip to Documents\sister-clan-rs3-tracker.
  2. Install Node.js LTS (big green button).
  3. Create a Discord app — clicks are in START-HERE.txt inside the zip.
  4. Double-click setup.bat, then start.bat. Leave that window open.
  5. In Discord: /setup clan:YourExactInGameClanName

Closing start.bat or sleeping the PC takes the bot offline. That is normal.

One-file installer

PowerShell, after Node.js is installed:
